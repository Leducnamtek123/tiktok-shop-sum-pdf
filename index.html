Hướng dẫn sử dụng nhanh

1

Tải Picking List từ TikTok

Khi shop có 400 - 1000 đơn, TikTok sẽ tách ra nhiều file PDF (mỗi file tối đa 200 đơn). Bạn tải tất cả các file về máy.

2

Kéo thả toàn bộ file vào web

Kéo chọn đồng thời 5 - 10 file PDF quăng vào khung bên trên. Hệ thống sẽ tự lọc món trùng nhau và cộng dồn số lượng chỉ trong 1 giây.

3

Xuất Excel hoặc In giấy A4

Bấm In phiếu khổ A4 để nhân viên kho cầm đi nhặt hàng một lượt, hoặc xuất file Excel gửi đối tác/lưu kho thuận tiện.
